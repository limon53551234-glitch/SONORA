Аккаунт SONORA

Рады видеть

Войдите, чтобы загружать музыку и получать прослушивания.

Пароль хранится на сервере только в виде PBKDF2-хеша.

Новый релиз

Загрузить трек

MP3-файл и обложка сохраняются на вашем C++ сервере. Имя файла на устройстве не используется как имя на сервере.

Размер проверяется сервером. Поддерживается MP3.
Обложка необязательна.

Подключение

Адрес API

Введите базовый URL C++ сервера без пути `/api`. Адрес сохраняется только в этом браузере.

Origin этой страницы: определяется браузером

GitHub Pages: потребуется разрешить её origin в `cors_origins` на сервере. Для HTTPS-сайта API тоже должен иметь HTTPS.
